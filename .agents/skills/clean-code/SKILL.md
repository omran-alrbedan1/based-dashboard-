# Clean Code

- Use clear domain names and focused components/functions.
- Deliberately model loading, empty, error, permission, and success states.
- Validate required vehicle-receipt fields before submission.
- Keep localized Arabic copy centralized once the Red Power locale namespace exists.
- Use semantic controls, labels, keyboard focus, and accessible status messages.
- Avoid generic utility dumping grounds; extract only behavior reused across domains.
- Verify the relevant build, type, lint, and focused tests before handoff.
